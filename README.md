# Student Management

A student management system built with Python and PostgreSQL.

## Getting Started

### Prerequisites
- Python 3.10+
- PostgreSQL

### Installation
1. Create and activate a virtual environment:
   ```bash
   python3 -m venv venv
   source venv/bin/activate
   ```
2. Set up environment variables:
   ```bash
   cp .env.example .env
   # Update .env with your database credentials
   ```
