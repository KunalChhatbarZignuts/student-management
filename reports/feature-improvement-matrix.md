## 1. Feature Assessment Matrix

| Feature / Module | Current Implementation Status | Lived User Problems & Limitations | Missing Real-World Capabilities | Recommended Improvements | Impact & Priority |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Authentication & Accounts** | JWT access/refresh tokens, password reset flow, role-based login, 2FA stub in backend | Students and young children often lack active emails; manual account unlocks require direct admin DB access | Phone OTP or Student ID + School PIN authentication; quick front-desk PIN reset | Add Quick Credential Recovery tool in Admin User Management; support Student ID + Master PIN login for younger students | Medium |
| **Admin Dashboard** | Metric cards (Total Students: 76, Faculty: 35), dark/light mode toggle, fast navigation | Only shows static headcounts; provides zero operational insight into today's school status | School-wide daily attendance rate, today's absent staff count, fee collection gauge, pending queues | Transform dashboard into an Operational Command Center with live daily attendance, staff coverage, and financial collection velocity | High |
| **Admissions (New Admission Wizard)** | 5-step wizard (`/admissions/create`) with candidate, guardian, previous schooling, and docs | Mid-year entrants get billed full annual fees; uploaded documents are not verified with status tags | Automated fee proration by admission month; formal document verification checklist (Birth Certificate, TC, Immunization) | Add mid-term fee proration policy and document verification approval workflow before student enrollment activation | High |
| **Admissions Applications Queue** | Queue view (`/applications`), applicant review modal, approve/reject triggers | Applicants cannot track their status online; no automated admission offer letter generation | Public Application Status Tracker with applicant tracking ID; printable PDF Admission Offer / Call Letter | Add public applicant tracking page and automated Offer Letter generator upon approval | Medium |
| **Student Directory & Profile** | 8-page paginated table, instant search, 6 detail tabs (Overview, Academics, Parents, Admissions, Attendance, Fees) | Class and section are freeform strings; no historical section transfer record; no emergency medical cards | Relational linkage to `Grade` & `Section`; Section Transfer dialog; Emergency Medical & Allergy registry | Enforce relational FKs for grade/section; add formal Section Transfer workflow; add Emergency Medical & Allergy card | **CRITICAL** |
| **Teacher Directory & Workload** | Faculty table (35 records), employee codes, department chips, details view | No visual workload balance indicator; teacher offboarding leaves orphaned class teacher and timetable assignments | Weekly period allocation gauge (e.g. 24/25 periods); Teacher Offboarding Reassignment Wizard | Add faculty period allocation gauge; build an Offboarding Reassignment Wizard to reassign classes atomically | High |
| **Grades, Sections & Shifts** | Academic year 2026-2027, 15 grades/sections, multi-shift configuration (Morning & Pre-Primary) | Class model in `classroom.py` duplicates `Grade`/`Section` in `academic_structure.py`; annual rollover is manual | Unified class representation; Bulk Annual Student Promotion & Rollover Wizard | Unify class schema; build an Annual Student Promotion & Rollover Wizard for end-of-year grade advancement | **CRITICAL** |
| **Timetables & Scheduling** | Multi-shift periods, weekly matrix view, clash detection engine, v1 draft/publish | Master timetable cannot be temporarily overridden for daily emergencies without altering permanent weekly schedule | Daily Schedule Override / Substitute Teacher Assignment engine; visual timetable diff changelog | Build a Daily Class Substitution Manager; add schedule change diffs and push notifications when timetable versions update | **CRITICAL** |
| **School Calendar & Holidays** | Interactive month grid, working days vs. holidays, working day details drawer | When a holiday is rescheduled to a Saturday, cannot specify which weekday's timetable to follow | Compensatory Working Day Schedule Remapping (e.g., "Saturday follows Tuesday's schedule") | Add `mapped_day_of_week` option when declaring compensatory working days | Medium |
| **Daily Attendance & Roll Call** | Section roll call, Present/Absent/Excused/Late buttons, bulk marking, audit history | Teachers locked out immediately upon submit; parents receive zero automated notifications of unexcused morning absence | 30-minute Teacher Amendment Grace Period; Automated SMS/Email/Push absence alerts dispatched upon roll call lock | Implement 30-minute teacher amendment window; dispatch automated absence alerts to parents after morning roll call | High |
| **Leave Monitoring & Approvals** | Student/Parent leave applications, Class Teacher review, status tabs, remarks | If assigned Class Teacher is absent, leave request freezes indefinitely; cannot attach medical certificates | Admin Fallback Approval for long-pending leaves; medical document attachment upload | Add Admin Approval fallback on `/leave-monitoring`; enable doctor's note / medical certificate upload on leave form | Medium |
| **Fee Structures & Ledger** | Component catalog, grade-wise structures, installments, online Razorpay webhook | In-person payments have no dedicated cashier POS window; no standard printable paper fee receipt | Front-Desk Cashier Counter POS (`/fees/counter`); print-ready PDF fee receipt with school seal | Build Front-Desk Cashier Counter POS screen with instant thermal/A4 fee receipt generation | High |
| **Fee Concessions & Partial Payments** | Backend `FeeConcession` model exists; partial payments update installment balance | Admin frontend lacks a dedicated Concession / Scholarship Catalog; voiding erroneous payments is complex | Structured Concession Categories (Sibling, Merit, Staff, EWS); Supervisor Void / Refund Payment action | Expose Concession Category management UI; add Supervisor "Void Payment & Reopen Installment" workflow | High |
| **Parent Portal Multi-Child** | Child switcher tabs (`/children`), individual bio, attendance, marks, timetable, fees | Separate fee transactions required per child; no consolidated family debt summary | Consolidated Family Fee Ledger with 1-click payment; automated sibling discount detection | Add Family Fee Overview card on Parent Portal; enable combined multi-child online payments | Medium |
| **Student Portal Experience** | Mobile-responsive dashboard, enrollment info, attendance stats (94.2%), timetable matrix | Offline corridor viewing fails if cellular network drops; no assignment file downloads or submission | Progressive Web App (PWA) offline schedule caching; digital assignment homework submission module | Add PWA service worker for offline timetable viewing; expand assignment tab with homework downloads and submissions | Medium |
| **Examination & Marks Engine** | Static course-level score display in student portal (`/marks`) | Teachers cannot enter exam marks; no calculation of term GPAs, grade boundaries, or class ranking | Complete Exam, Term, Gradebook entry, GPA calculation, and Official Printable Report Card PDF generator | Build Teacher Gradebook score entry interface; implement automated Report Card PDF generator | **CRITICAL** |
| **Audit Logs & Governance** | Immutable security trail with 538+ events, actors, actions, timestamps, and IPs | Does not show structured before/after field value diffs; no field-level restore capability | Structured JSON before/after state diffs; field-level change comparison modal | Enhance audit log detail drawer to render before/after JSON diffs for sensitive student and fee mutations | Medium |

## 2. Summary by Quality Dimension

- **Data Integrity & Consistency:** 2 Critical areas (Unified Academic Class representation; Exam & Gradebook architecture).
- **Daily Operational Efficiency:** 3 High areas (Daily Substitution Manager; Annual Promotion Wizard; Front-Desk Cashier POS).
- **Child Safety & Parent Communication:** 2 High areas (Automated Absence Alerts; Emergency Medical & Pickup Registry).
- **User Interface & Experience:** 3 Medium areas (Teacher Attendance Grace Window; Consolidated Family Fee Ledger; PWA Offline Schedule).
